06Documentation

Setup, commands and fixes, in one place.

The extension gets you ready; the agent does the work. The framework repository is the authoritative reference, and a fuller user guide ships with the extension (docs/USER_GUIDE.md in the install folder).

How to use it, step by step

1
Install the extension. The AL toolchain and both agent extensions come with it.
2
Follow the walkthrough. It opens automatically, or run Help: Open Walkthrough → Set up the OCPF BC Framework. Check Git first: both agents install the plugin by cloning its repository. If Git is missing you get an Install Git button that runs the right installer for your OS in a terminal you can watch; nothing installs silently. After the install, quit and reopen VS Code completely (not Reload Window) so it sees the new Git. Then Choose your AI agent (Claude Code, GitHub Copilot, or both); this wires the agent to the framework's plugin marketplace and installs the ocpf-bc plugin, with you confirming each step.
3
Start a project with one of the Command Palette commands. The plugin then helps you choose Build-a-Feature, Full (recommended), or Lite, installs the latest runbook, connects Microsoft's AL tools, adds sub-agents for the Reasoning, Light, Generator and Reviewer roles (and an Analyst when you document an existing app), and checks for updates each session before changing anything.
4
Hand off to the agent. In your agent's chat panel, run /ocpf-bc:start. The agent fetches the framework's runbook, standards guide and templates into your project and takes it from there: plain-language requirement in, tested AL extension out.

Commands · Command Palette, category “OCPF BC”

OCPF BC: New AL Project + Framework
Runs Microsoft’s AL project wizard to scaffold a fresh AL project, waits for it to be created (even across the window reload the wizard can trigger), then rolls straight into the kickstart.
OCPF BC: Kickstart Framework Here
For an AL project that is already open. Verifies Git, asks which agent you will use, wires it, then opens the chat panel pointed at /ocpf-bc:start. It stops there on purpose; fetching framework artifacts is the agent’s job.
OCPF BC: Set Up Claude Code
Checks whether the ocpf-bc plugin is already installed and, if so, says so (version and scope) and skips the install; otherwise wires Claude Code to the plugin marketplace and installs the plugin via Claude Code’s own confirm dialog. A Reinstall anyway button is there if you need it. Re-runnable any time.
OCPF BC: Update the ocpf-bc Plugin
Runs the freshness check on demand: repairs Claude Code's marketplace cache, turns on auto-update for the framework's marketplace, compares the installed plugin with the latest on GitHub, and updates. The same check runs by itself on every VS Code start, at most once every six hours.
OCPF BC: Set Up GitHub Copilot
Enables Copilot agent plugins, registers the framework’s plugin marketplace in your settings, and points you at the plugin in the Extensions view. Re-runnable any time.
OCPF BC: Check Git Installation
Verifies git is on your PATH; offers a watch-it-happen install if not.

Agent plugin commands · /ocpf-bc:

Start here
/ocpf-bc:start
Starts a project: choose Build-a-Feature (no steps), Full (14 steps, the recommended journey) or Lite (7), installs the latest runbook, connects the AL tools, begins the routine. On a project already on the framework it offers status, an update check, or building a feature.
/ocpf-bc:status
Reports where the project stands: phase, step, exit gate, what is waiting on you. Great when resuming a session.
/ocpf-bc:build-a-feature
Builds one object at a time, in minutes, in a new or existing per-tenant extension: a table and its pages, a page or table extension, an API page, a report, an enum, a codeunit, a permission set, a role center. No steps, six short documents, the same standards and analyzers.
/ocpf-bc:analyze
Reverse-engineers an existing, undocumented extension into a presumed FRD, TDD, Object Register, Documentation and parameters sheet under requirements/existing/, for you to review before any journey extends it.
On demand
/ocpf-bc:al-standards
Loads the OCPF AL Development Standards Guide for writing and reviewing AL code.
/ocpf-bc:skill-load
Loads a Custom Skill from a folder, a zip, a GitHub repository (public, or private through your own sign-in), a bcskills.ai slug, or a skillslocation.md list; checks it against the framework version, the journey, and the other skills, and shows it before activating. See the Skills page.
/ocpf-bc:skill-create
Turns what worked in this project into a Custom Skill of your own: slug, author, journeys, extension points, a folder under ~/.ocpf/skills/, and a GitHub repository with the ocpfbcskills topic if you want one.
/ocpf-bc:skill-update
Versions a loaded skill: shows the diff, asks patch, minor, or major and the changelog line, writes the new version back, pushes on a yes, and re-checks the project.
/ocpf-bc:update-framework
Checks for a newer runbook, shows what changed, updates only with your approval.

Troubleshooting

I installed Git, but VS Code still says it is missing.
VS Code only picks up newly installed programs at startup. After installing Git, quit and reopen VS Code completely (File → Exit on Windows, Code → Quit on macOS; Reload Window is not enough), then run OCPF BC: Check Git Installation again. On Windows the extension tells the two cases apart: when Git is in its install folder but not yet visible to the window, it says to restart rather than reinstall.
Git asks who you are, or commits fail with an identity error.
Git needs your name and email once per machine. Open the terminal in VS Code (Terminal → New Terminal), or Command Prompt on Windows, and run, with your own details in the quotes:
git config --global user.email "you@example.com"
git config --global user.name "Your Name"
You only do this once; every project on the machine uses it from then on.
My AL files show red squiggly underlines, but the code compiles and the agent says there are no errors.
The AL language service occasionally gets out of sync with the code on disk. Open the Command Palette (Ctrl+Shift+P, or Cmd+Shift+P on Mac), type Developer: Reload Window, and press Enter. The squiggles disappear after the reload.
Claude Code does not show a command or journey the documentation mentions (for example, /ocpf-bc:start offering only Full and Lite).
Your ocpf-bc plugin is behind. Run OCPF BC: Update the ocpf-bc Plugin from the Command Palette and click Update now, then start a new Claude Code session. If it tells you to update inside Claude Code, type /plugin there, pick ocpf-bc, choose Update. The extension also runs this check on every VS Code start, so after the first time it takes care of itself.
Something else?
Report it on the framework’s issues page, with what you clicked and what you saw.

Agent plugin commands · the runbook runs these for you · run them yourself to repeat or repair

/ocpf-bc:roles
Asks which AI models do the work (and thinking effort), and makes the choice take effect.
/ocpf-bc:notifications
Turns on notifications for when the agent finishes, asks, or waits on you.
/ocpf-bc:dashboard
Creates, refreshes, or opens the project's live HTML dashboard, the Build Map page.
/ocpf-bc:al-mcp-setup
Connects the AI to Microsoft’s AL tools (build, compile, symbols, diagnostics). Nothing to install.
/ocpf-bc:usage
Measures what the project has consumed per step and per model, tokens in Claude Code and AI credits in GitHub Copilot, with time, turns, decisions and cost, and refreshes the usage table in ProjectProgress.md.
/ocpf-bc:documents <name>
Writes any framework document (FRD, TDD, Build Plan, ChangeLog, FAQ and more) from its official template into docs/. With no name it asks which, several at once, and can hand off to the help site.
/ocpf-bc:app-icon
Draws an app icon when you have none: style, colors and content asked in one box, the SVG rendered to PNG and shown, accepted or redrawn, then set as app.json's logo.
/ocpf-bc:html-docs
Builds the extension's help site, docs/index.html: tabs for the User Guide, the Documentation, an FAQ and the Deployment guide, your screenshots, a download button, and the steps to publish it on GitHub Pages. Offered at Full Step 11 and Lite Step 6.
/ocpf-bc:copilot-blueprint
Builds a Business Central Copilot feature the verified way, from the OnlyBCFans BC Copilot Blueprint: PromptDialog pages, capability registration, Azure OpenAI through System.AI. Works in any journey.
