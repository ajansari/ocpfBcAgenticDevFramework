# ANZ Agentic Dev Framework Outline

## DEFINE

- **PRE-01. State the Problem**
- **PRE-02. Structured Gap Analysis**
- **01. Populate the Intake Sheet (Standards Guide)**

## DESIGN

- **02. Craft Functional Requirements Document (FRD)**
  - Review and validate against artifacts from the DEFINE phase.
- **03. Craft Technical Design Document (TDD)**
- **04. Sanity Check and Validation**
  - Is this possible in BC? Does the TDD follow the FRD? What will the structure look like?

## BUILD

- **05. Plan the Code**
  - In which order will objects be built?
- **06. Code Generation**
  - Lint (dot the i's, cross the t's) and test individual code files as you go.
- **07. Troubleshoot, Iterate**

## PROVE

- **08. Gap-Fit Test, Fidelity Validation**
  - Does the written code follow the TDD and FRD? What changed? Why?
- **09. Package and Test App**
- **10. Code Review**
  - Check for code quality, dead code, redundant code, and "marked for obsoletion" items.
- **11. Update Design Documents**
  - Create a new TDD version reflecting changes to the architecture.
  - Create a new FRD as a baseline for future development.
- **12. Document the Code**
  - Create documentation / user guide.
  - Create a human unit test script.

## All Along

- Document, track changes (change log), and retain explanations.
