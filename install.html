Install the extension. Open your AL project. Type one command.

Recommended install
Works with

The framework works for brand-new apps and for adding functionality to existing apps: start a new AL project with it, or kickstart it inside the one you already have.

Install the OCPF BC Dev Setup extension from the Visual Studio Code Marketplace. One click installs the AL toolchain, wires your AI agent (Claude Code or GitHub Copilot), and kickstarts the framework in your project.
