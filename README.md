# ocpfBcAgenticDevFramework
The OnlyCopilotFans Business Central Agentic Development Framework - by AJ Ansari

Last Updated: Friday, September 4, 2026

## Background
This Agentic Development Framework with created to help Business Central Functional Consultants who want to use AI to create AL Extensions and apps the **right** way. But the framework can also be used by professional AL developers.

## Table of Contents
- **`The OCPF BC Agentic Dev Framework Outline.md`** - This file contains a raw outline of the various Stages and Steps in the development framework. Review this to get a high level understanding of the framework
- **`BC_App_Build_Routine_Agent.md`** - This is the file that consultants and developers can drop in any new AL project in Visual Studio Code. Review and make changes as necessary, then initialize the process with this simple prompt:
  `This AL project will follow the Agentic Development Framework outlined in "BC_App_Build_Routine_Agent.md". Please review this file and let's get started.`

- **Building with the Claude Code plugin in Visual Studio Code?** Rename `BC_App_Build_Routine_Agent.md` to `CLAUDE.md` and save the file in the project root folder.

- **Building with GitHub Copilot Chat in Visual Studio Code?** Rename `BC_App_Build_Routine_Agent.md` to `copilot-instructions.md` and save the file in a new subfolder called `.github` in the root folder.
